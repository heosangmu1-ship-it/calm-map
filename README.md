# 무던한 지도 (Calm Map)

AI 라이프 솔루션 챌린지(KEIT 공고 2026-614) 시제품. 발달장애 아동 가족이 외출 전에 장소와 시간대별 소리·혼잡 부담을 미리 보는 정적 웹앱 (서버, 키, 계정 없음).

- 폰 마이크 소리를 폰 안에서 YAMNet(TensorFlow.js)으로 분류한다. 원음은 저장·전송하지 않는다.
- 서울 생활인구(공공데이터, 공공누리 1유형)로 시간대별 혼잡을 추정한다. 모르는 값은 0이 아니라 "정보 부족"이다.

## AI 사용 고지
- 앱 안의 소리 분류는 Google YAMNet 모델(온디바이스)이다. 문장과 이야기 카드는 규칙으로 채우며 생성형 AI를 쓰지 않는다.
- 이 앱의 코드와 문서는 AI 코딩 도구(Claude)의 도움을 받아 작성했다.

## 시연 측정 고지
지도의 상업 시설 6곳 값은 "시연용 가상 측정"이며 실제 매장 값이 아니다. 실제 공공장소 8곳은 소리 측정이 없어 "정보 부족"으로 표시된다. 소리 크기는 폰 마이크의 상대값(dBFS)이며 SPL이 아니다. 지수는 환경 정보이며 아이의 반응을 진단하거나 보장하지 않는다.

## 라이선스와 출처
제3자 구성요소의 라이선스는 [NOTICE.md](NOTICE.md) 참조 (TensorFlow.js, YAMNet: Apache-2.0, 시험 소리 샘플: 공개 도메인/CC0, 서울 생활인구: 공공누리 1유형).

## 로컬 실행
`python3 -m http.server 8000` 후 http://localhost:8000 (마이크는 localhost 또는 HTTPS에서만 허용).
